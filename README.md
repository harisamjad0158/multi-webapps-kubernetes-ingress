# multi-webapps-kubernetes-ingress
A multi-application Kubernetes deployment using Kind, Docker, NGINX Ingress, and Apache. Hosts four web applications across eight Pods and three Kubernetes nodes, with path-based routing through a single NGINX Ingress Controller.
